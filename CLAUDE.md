# Help Finder

A Discord bot + dashboard that matches stuck cohort builders with the right peer, based on tech stack analyzed from public GitHub repos. No user sign-up needed — data is pulled automatically from the cohort's public submission repos.

## Repo structure

```
backend/        # Ori — Python ingest pipeline + Discord bot
frontend/       # Johnny — Next.js dashboard
data/           # Shared: participants.sample.json (mock) + participants.json (real, gitignored)
```

## Branches

- `feature/backend` — Ori owns this
- `feature/frontend` — Johnny owns this
- Don't touch the other person's branch without asking

## Key commands

```bash
# Backend
cd backend
python ingest.py              # full pipeline: scrape → analyze → summarize → write data/participants.json

# Frontend
cd frontend
npm run dev                   # start dev server at localhost:3000
```

## Data schema

Single source of truth: `data/participants.json` (generated by ingest, not hand-edited).
Schema is defined in `TICKETS.md` — do not change field names without coordinating with both Ori and Johnny.

## Environment variables

```
GITHUB_TOKEN=       # required — GitHub personal access token (avoids rate limits)
GROQ_API_KEY=       # optional — Groq free tier for README summarization; falls back to first README paragraph if unset
```

Copy `.env.example` to `.env` in the `backend/` directory.
