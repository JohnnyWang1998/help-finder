# Help Finder — Backend

Python ingest pipeline and Discord bot for the cohort help-finder.

## Data schema

`data/participants.json` is generated by ingest (do not hand-edit). Field names match [TICKETS.md](../TICKETS.md):

| Field | Type | Notes |
|-------|------|--------|
| `githubHandle` | string | |
| `name` | string | |
| `avatarUrl` | string | `https://github.com/{handle}.png` |
| `repoUrl` | string | |
| `liveUrl` | string | optional |
| `pitch` | string | from submission |
| `summary` | string | README summary or fallback |
| `techStack` | string[] | normalized tags |
| `languages` | object | lang → bytes |
| `lastCommitAt` | ISO 8601 | |
| `commitsLast7d` | number | |
| `repoPrivate` | boolean | |

Day 1 mock: `data/participants.sample.json` (3 entries).

## Setup

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env   # set GITHUB_TOKEN
```

## Commands

```bash
python scrape_submissions.py  # fetch submission JSON stubs (A2; needs GITHUB_TOKEN)
python ingest.py              # scrape → analyze → summarize → write ../data/participants.json
python bot.py                 # Discord /help and /peers (needs DISCORD_BOT_TOKEN)
pytest                        # unit tests (skips integration by default)
pytest -m integration         # live GitHub ingest (needs GITHUB_TOKEN)
```

## Package layout

- `help_finder/models.py` — `Participant` dataclass
- `help_finder/submissions.py` — cohort submission fetch/parse
- `help_finder/analyzer.py` — tech stack from GitHub
- `help_finder/summarizer.py` — README summary + cache
- `help_finder/activity.py` — commit activity
- `help_finder/matching.py` — fuzzy rank (shared with bot)
- `help_finder/pipeline.py` — orchestration
- `help_finder/discord_app.py` — slash `/help` and `/peers`
- `help_finder/matching.py` — fuzzy rank, stack overlap, query normalization
- `help_finder/clients/` — GitHub + LLM protocols and implementations
